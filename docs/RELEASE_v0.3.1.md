# v0.3.1 — Menu bar tray & About

## Highlights

- **Menu bar tray** — DeskNinja stays accessible from the macOS menu bar; left-click toggles the panel
- **Tray menu** — Open (⌘J), About DeskNinja, Quit
- **Native tray icon** — monochrome template icon (Stash-style) that adapts to light/dark menu bar
- **About dialog** — version info from the app bundle; reachable from tray and panel header
- **Quit fix** — tray Quit reliably exits the app while window dismiss still keeps DeskNinja running

## Notes

- Unsigned build: right-click → **Open** on first launch, or `xattr -cr /Applications/DeskNinja.app`

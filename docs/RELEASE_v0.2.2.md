# v0.2.2 — Open at cursor

## Highlights

- **⌘⇧Space** opens DeskNinja next to the mouse cursor (same positioning logic as [Stash](https://github.com/pc6n/stash))
- Press again to **hide** the window (toggle)
- Window stays within the monitor work area (below cursor when possible, otherwise above)

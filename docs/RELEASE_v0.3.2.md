# v0.3.2 — Chat todos, resizable panel & Markdown

## Highlights

- **`/todo` from chat** — type `/todo Buy milk` in chat to create a todo; mixed messages still send the rest to the model
- **Resizable panel** — drag edges or bottom-right corner to resize the quick panel; size is remembered
- **Markdown rendering** — assistant replies show paragraphs, lists, headings, links, and code blocks
- **Copy code blocks** — one-click copy icon on fenced code in chat and context actions
- **Clearer model output** — system prompt encourages structured Markdown responses

## Notes

- Unsigned build: right-click → **Open** on first launch, or `xattr -cr /Applications/DeskNinja.app`

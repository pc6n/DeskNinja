# v0.2.0 — Todos & global shortcut

## Highlights

- **Todo tab** — manage tasks with local persistence (`~/Library/Application Support/com.deskninja.app/todos.json`)
- **Global shortcut** — `Command+Shift+Space` shows and focuses the main window from any app
- Tab navigation between **Chat** and **Todos** with open-task count badge

## Download

macOS `.dmg` (Apple Silicon) on [GitHub Releases](https://github.com/pc6n/DeskNinja/releases/tag/v0.2.0).

## Known limits

- Shortcut requires DeskNinja to be running (background or visible)
- macOS may conflict if `⌘⇧Space` is already assigned in System Settings
- Unsigned build — right-click → Open on first launch
- Quick panel and cloud providers still on the roadmap

See `docs/IMPLEMENTATION_PLAN.md` for next milestones.

# v0.3.3 — Chat context tokens

## Highlights

- **Context usage bar** — see how much of the model context your chat is using
- **Cumulative estimate** — grows with the full conversation, not just the last prompt
- **Model limits** — progress bar against each model's context window (e.g. 128k for Llama 3.2)
- **Last reply tokens** — separate count for the most recent assistant response
- **Ollama integration** — reads `prompt_eval_count` and `eval_count` from streamed responses

## Notes

- Unsigned build: right-click → **Open** on first launch, or `xattr -cr /Applications/DeskNinja.app`
